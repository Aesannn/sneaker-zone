# SNEAKER ZONE — DEFY THE VOID

A high-end, futuristic 3D sneaker showroom built with Three.js, GSAP, and Lenis. Experience the next generation of digital retail.

## 🚀 Features

- **3D Interactive Showroom**: Real-time rendering of sneakers with dynamic theme switching (Devil, Phantom, Bloodmary).
- **Holographic HUD**: Interactive diagnostic elements and spec-floats that react to scroll and mouse movement.
- **X-Ray Sidebar**: Real-time system diagnostics and wireframe visualization.
- **Size Picker Modal**: A robust, "collider-style" size selection system with precise state management.
- **Advanced Animations**: Smooth parallax, glitch effects, scan-up reveals, and bag-centric "+1" cart animations.
- **Performance Optimized**: Smooth 60fps scrolling and optimized asset loading.

## 🛠 Tech Stack

- **Three.js**: 3D engine and rendering.
- **GSAP**: High-performance animation engine.
- **Lenis**: Smooth scrolling architecture.
- **Vite**: Modern frontend build tool.
- **Vanilla CSS/JS**: For maximum control and performance.

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Aesannn/sneaker-zone.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

## 🌐 Deployment

Hosted on **Vercel**. Connect your GitHub repository for automatic deployments.
